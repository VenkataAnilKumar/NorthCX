How memory and instructions work together

Memory is what assistants have learned about you. Instructions are what you or your organization told them to do. If they conflict, instructions win, and organization rules win over both. Memory never overrides a policy, a fact from a source, or a customer's data.

Keep it honest

Memory should not make an assistant simply agree with you. Assistants still cite sources and say when a source disagrees with a remembered preference. Review memory now and then; items unused for 90 days are offered for removal.
