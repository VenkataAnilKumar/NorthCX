# NorthCX Database Schema

Status: **Built**. Updated: 2026-11-09. Master for: database tables (checked by a test). The tables marked **built** exist in the migrations (`0001` to `0030`) and match `northcx/db/models.py` (a test checks that the migrations and the models agree); rows without that marker are early proposals that were not built as written (agents and releases became `agent_versions` and `releases`, scenarios became `managed_scenarios`, experiments became `rollouts`).

| Table | Columns | Notes |
|---|---|---|
| `sessions` (built) | `id` pk, `created_at`, `updated_at` | No customer, agent or channel columns: the customer link is `session_index`, the agent is on `traces` and `session_routes`, the channel is in the channel tables |
| `messages` (built) | `id` identity pk, `session_id` fk (cascade), `seq`, `role`, `content` jsonb | Unique (`session_id`, `seq`); history is replaced atomically on save |
| `customer_facts` (built) | `customer_id`, `key`, `value`, `updated_at` | pk (`customer_id`, `key`); `source_trace_id` later |
| `traces` (built) | `id` pk, `session_id`, `agent_id`, `agent_version`, `status`, `started_at`, `tools` jsonb, `event_count` | Summary columns written at save so lists never load events |
| `trace_events` (built) | `id` identity pk, `trace_id` fk (cascade), `seq`, `type`, `t`, `data` jsonb | Unique (`trace_id`, `seq`) |
| `approvals` (built) | `id` pk, `trace_id`, `session_id`, `agent_id`, `customer_id`, `tool`, `input` jsonb, `reason`, `state`, `created_at`, `decided_by`, `decided_at`, `note`, `result` jsonb | State machine in the Handoff and Approvals spec; every transition is an atomic conditional update (migration 0002 added the context, note and result columns) |
| `outbox` (built) | `id` identity pk, `session_id`, `kind`, `payload` jsonb, `created_at`, `delivered_at`, `attempts` | Index (`session_id`, `id`); undelivered rows are retried |
| `email_sessions` (built) | `session_id` pk, `sender`, `subject`, `last_message_id`, `references` jsonb, `customer_id`, `verified`, `created_at` | One row per email conversation |
| `email_messages` (built) | `message_id` pk, `session_id`, `direction` (in/out), `status`, `peer`, `created_at` | Dedupe by Message-ID; index (`peer`, `direction`, `created_at`) for per-sender limits; `outbox.last_attempt_at` drives back-off |
| `monitor_findings` (built) | `id` pk, `rule`, `severity`, `detail`, `trace_id`, `session_id`, `agent_id`, `agent_version`, `created_at` | Indexes on time, (rule, time), session |
| `idempotency_keys` (built) | `scope` pk (hash of caller, agent, conversation, key), `req_hash`, `response` jsonb (null while running), `created_at` | Expired after 24 h |
| `knowledge_sources` (built) | `id` pk, `name`, `stale_after_days`, `created_at` | |
| `knowledge_documents` (built) | `id` pk, `source_id` fk (cascade), `external_id`, `title`, `url`, `content_hash`, `chunks`, `source_updated_at`, `ingested_at` | Unique (`source_id`, `external_id`) |
| `knowledge_chunks` (built) | `id` identity pk, `document_id` fk (cascade), `seq`, `heading`, `body`, `search_text`, `tsv` (generated full-text vector) | GIN index on `tsv`; deleting a document removes its passages |
| `session_index` (built) | `session_id` + `customer_id` pk (`''` = no known customer), `first_seen`, `last_seen` | Written on every turn; drives export, erasure and retention; `idempotency_keys.session_id` links stored replies to a conversation |
| `customer_memories` (built) | `id` pk, `customer_id`, `text` (max 300), `text_hash`, `source_session`, `created_at`, `updated_at`, `tsv` (generated) | Unique (`customer_id`, `text_hash`); GIN index on `tsv`; at most 200 per customer |
| `inbox_events` (built) | `id` pk, `handoff_id`, `connector`, `event` (created/resolved), `created_at`, `attempts`, `last_attempt_at`, `delivered_at`, `external_ref`, `error` | Delivery queue to helpdesks; retried with back-off up to 12 attempts; erased with the hand-off |
| `trace_exports` (built) | `id` pk, `trace_id`, `exporter`, `created_at`, `attempts`, `last_attempt_at`, `delivered_at`, `error` | Queue of traces to send to observability backends; retried with back-off up to 12 attempts; erased with the conversation |
| `conversation_feedback` (built) | `session_id` pk, `rating` 1-5, `comment`, `created_at` | One rating per conversation; erased with it |
| `voice_calls` (built) | `call_id` pk, `session_id`, `agent_id`, `caller_hash`, times, `outcome`, `consent`, `recorded`, `turns`, `barge_ins`, `languages`, `handoff_id`, `latency_ms` | No audio and no phone number; erased with its conversation |
| `attachments` (built) | `id` pk, `session_id`, `name`, `kind`, `media_type`, `size`, `sha256`, `data` (bytes), `uploaded_by`, `created_at` | At most 20 files and 40 MB per conversation; erased with it |
| `session_routes` (built) | `session_id` pk, `agent_id`, `updated_at` | Which agent a conversation is currently with after transfers; erased with it |
| `rollouts` (built) | `id` pk, `agent_id`, `environment`, `candidate_number`, `control_number` (null: spec file), `percent`, `state` (active, promoted, aborted), `started_by`, `ended_by`, times | At most one active per agent and environment (partial unique index) |
| `rollout_assignments` (built) | (`rollout_id`, `session_id`) pk, `arm` | Fixes each conversation's arm; erased with the conversation |
| `conversation_reviews` (built) | `session_id` pk, `verdict`, `handoff`, `failures` (jsonb), `note`, `reviewer`, `reviewed_at` | One review per conversation, a new one replaces it; erased with the conversation |
| `conversation_tags` (built) | (`session_id`, `tag`) pk, `by`, `created_at` | At most 20 tags per conversation; erased with it |
| `traces.environment` (built) | `varchar(32)`, default `production` | Which environment answered the turn |
| `api_keys` (built) | `key_id` pk, `name`, `role`, `key_hash`, `created_by`, `created_at`, `expires_at`, `revoked_at`, `revoked_by`, `last_used_at`, `agents`, `environments`, `extra_roles` | Only the SHA-256 hash of the secret is stored (migration 0006). `agents` and `environments` (JSON lists, null for no limit) limit what a key can reach (0033); `extra_roles` are the roles a sign-in session got from groups (0034); `tenant_id` says whose key it is (0037) |
| `scim_users` (built) | `id` pk, `user_name` (unique, the sign-in email), `display_name`, `external_id`, `active`, `created_at`, `updated_at` | People provisioned by SCIM; an inactive person cannot sign in (migration 0035) |
| `release_requests` (built) | `id` pk, `agent_id` (indexed), `kind`, `environment`, `version`, `requested_by`, `note`, `status`, `decided_by`, `decision_note`, `created_at`, `decided_at` | A publish or promote waiting for a second person; one decision wins (migration 0036) |
| `tenants` (built, first slice) | `id` pk, `name`, `status` (active or suspended), `created_at` | Tenants; the `default` tenant is seeded (migration 0037). Isolation of other tables is not built: see `NorthCX_Tenancy-ADR.md` |
| `channel_bindings` (built, not yet used by the channels) | `kind` + `address` pk, `tenant_id` (indexed), `created_at` | An inbound number, bot id or email domain belongs to one tenant (0037) |
| `groups` (built) | `id` pk, `name` (unique), `external_name` (unique, nullable), `description`, `roles` (JSON), `members` (JSON), `created_by`, `created_at` | Roles bound to sets of people (hand-added subjects and an identity provider group name); a person's permissions are the union over their groups (migration 0034) |
| `agent_versions` (built) | `id` pk, `agent_id`, `number`, `spec` jsonb, `digest`, `author`, `note`, `created_at` | Unique (`agent_id`, `number`); immutable; numbers assigned under a per-agent lock (migration 0005) |
| `releases` (built) | `seq` identity pk, `id`, `agent_id`, `environment`, `action` (publish/rollback), `version_id` fk (null = spec file), `number`, `previous_number`, `by`, `note`, `gate` jsonb, `created_at` | Append-only; newest by `seq` is live; index (`agent_id`, `environment`, `seq`) |
| `handoffs` (built) | `id` pk, `session_id`, `trace_id`, `agent_id`, `customer_id`, `trigger`, `reason`, `topics` jsonb, `package` jsonb, `state`, `created_at`, `resolved_by`, `resolved_at`, `note` | Indexes (`state`, `created_at`) and `session_id`; resolve is an atomic conditional update (migration 0003); `queue` arrives with routing |
| `audit_log` (built) | `id` pk (assigned under a lock, gapless), `at`, `actor`, `role`, `key_id`, `action`, `target`, `outcome`, `detail` jsonb, `prev_hash`, `hash` | Append-only: triggers refuse UPDATE, DELETE and TRUNCATE; the hash chain exposes edits made around them (migration 0006) |
| `simulation_runs` (built) | `id` pk, `created_at`, `mode`, `source`, `passed`, `seconds`, `counts` jsonb, `agent_digests` jsonb, `meta` jsonb, `results` jsonb | Index on `created_at`; results hold per-scenario digests used by the gate (migration 0004); `agent_version_id` replaces digests once versions exist |

| `managed_scenarios` (built) | `name` pk, `agent_id`, `required`, `definition` jsonb, `created_by`, `updated_by`, `created_at`, `updated_at`, `revision` | Scenarios saved by the editor; run and gated like file scenarios; a name used by a file belongs to the file |
| `knowledge_documents.body` (built) | `text`, nullable | The document as submitted, so it can be edited; null for documents saved before this column existed |
| `sms_sessions` (built) | `session_id` pk, `phone`, `our_number`, `created_at`, `last_seen` | Shared by SMS, WhatsApp and Telegram: `phone` is the sender (`+number`, or `tg:<id>` for Telegram) and `our_number` is the number, phone-number id or bot id it came in on; index (`phone`, `our_number`, `last_seen`) |
| `sms_messages` (built) | `message_id` pk, `session_id`, `direction` (in/out), `outcome`, `peer`, `created_at` | Dedupe by provider message id; per-sender hourly limits; messages that belong to no conversation are recorded under a one-way reference, so erasing a customer leaves no number behind |
| `sms_opt_outs` (built) | `phone_hash` pk (SHA-256 of the sender), `updated_at` | STOP is honoured even after the customer's data is erased; covers every messaging channel |
| `crawl_schedules` (built) | `id` pk, `source_id` fk (cascade), `config` jsonb, `every_hours`, `next_run`, `last_run`, `last_job_id`, `last_result`, `enabled`, `created_by`, `created_at` | A saved crawl request; due runs are claimed atomically so several server processes run each once per interval; index (`enabled`, `next_run`) |
| `verification_codes` (built) | `session_id` pk, `customer_id`, `channel`, `dest_hash`, `code_hash` (null once used or cancelled), `expires_at`, `attempts`, `sends` jsonb, `verified_until`, `updated_at` | One-time identity codes: only keyed hashes are stored, never the code or the address; erased with the conversation |
| `rate_counters` (built) | `key` + `window_start` pk (epoch seconds, database clock), `count` | Requests counted per key per fixed window, shared by all server processes when `NORTHCX_LIMITS_BACKEND=postgres`; windows older than two hours are deleted |
| `usage_ledger` (built) | `agent_id` + `day` (UTC) pk, `tokens`, `cost_micros` | Model tokens and money (millionths of the budget currency) used per agent per day, shared by all server processes under the same setting; read for the daily token and money budgets |
| `model_qualifications` (built) | `id` pk, `agent_id` (indexed), `model`, `created_at`, `result` (JSON) | Whether a model passed an agent's scenarios for one agent definition, with the run that proves it; the newest row per agent and model decides (`providers/qualification.py`) |
| `job_leases` (built) | `name` pk, `holder`, `expires_at` (database clock) | Which server process runs a named background job right now (outbox, approvals, trace export, alerts, inbox, retention); a process that dies mid-pass simply lets its lease expire |
| `alert_state` (built) | `rule` pk, `payload` jsonb | Alerts that are firing right now, so whichever process evaluates next does not fire them again |
| `alert_events` (built) | `id` pk, `at`, `payload` jsonb | The last 200 alert events with delivery status, readable from any process |
| `crawl_jobs` (built) | `id` pk, `source_id`, `state`, `started_at`, `updated_at` (heartbeat), `payload` jsonb | Website crawls and their progress, readable from any process; a running crawl with a recent heartbeat blocks a second crawl of the same source |
| `knowledge_embeddings` (built, created on demand) | `chunk_id` pk fk (cascade to `knowledge_chunks`), `model`, `embedding` (pgvector, any size), `created_at` | Created at start-up when meaning-based search is configured (needs the pgvector extension), so deployments without it never need the extension; an HNSW index per vector size (`ix_ke_hnsw_<size>`) is built automatically past a size threshold; dropped by a full downgrade |

**Tables proposed earlier and not built, because other tables do the job:** `agents` (versions are in `agent_versions`), `environments` (each release names its environment in `releases`), `scenarios` (saved scenarios are `managed_scenarios`; file scenarios stay files), `experiments` (staged rollouts are `rollouts` and `rollout_assignments`).

**Retention.** The retention job (`NORTHCX_RETENTION_DAYS`) erases idle conversations with everything linked to them; the audit log is append-only and is never erased.

**After 1.0.** The staff platform adds tables (provisional names in `NorthCX_Staff-Platform-Architecture.md`, section 4); each is added here when its migration lands, and multi-tenancy adds `tenant_id` to every table (E2).
